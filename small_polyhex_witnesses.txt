SMALL_POLYHEX_WITNESSES_V1
#
# Integer certificates for the polyhexes with at most six hexagons.
#
# There are 116 such polyhexes up to translation and the dihedral symmetries
# of the tiling, with 1, 1, 3, 7, 22, 82 of them on 1, ..., 6 cells; the ring
# of six cells around a hole is amongst them.  Exactly three lie in the
# golden gap class, that is, have no adjacency eigenvalue in the open
# interval (-theta, theta) where theta = (sqrt5 - 1)/2 = 1/phi.  This file
# records, for each of the other 113, an integer vector y supported on one
# colour class which certifies that its graph does have an eigenvalue there,
# and for each of the three, the data of a characteristic-polynomial
# certificate.  The three are benzene, naphthalene and triphenylene, which
# agrees with the survivors reported by the shipped C++ verifier in
# seven_hexagon_verification_fresh.log, namely h=1 (0,0); h=2 (0,0)(0,1);
# h=4 (0,1)(1,1)(1,2)(2,0).
#
# The test.  Let X be the graph of the polyhex, with adjacency matrix A, and
# let y be an integer vector supported on one colour class.  Since
# theta^2 = 2 - phi,
#
#     y^T (A^2 - theta^2 I) y  =  y^T (A^2 - 2I) y + phi y^T y
#                             =  phi N - M,
#
# where N = y^T y > 0 and M = -y^T (A^2 - 2I) y are integers.  Hence
#
#     y^T (A^2 - theta^2 I) y < 0
#        <=>  phi N < M
#        <=>  (1 + sqrt5) N < 2M
#        <=>  sqrt5 N < 2M - N
#        <=>  2M - N > 0  and  5 N^2 < (2M - N)^2,
#
# the last step because N > 0, so the left side of the previous line is
# positive and squaring is reversible exactly when the right side is
# positive too.  These are two strict inequalities between integers.  Since
# A^2 is block diagonal with respect to the two colour classes, if
# A^2 - theta^2 I fails to be positive semidefinite then one of the two
# colour blocks does, so a single-colour witness always exists.  No
# relaxation is involved: the graph is fully known, so M is exact.
#
# Conventions.  The cell (q, r) in axial coordinates has centre (2q+r, 3r)
# and vertices at the six offsets (1,1), (0,2), (-1,1), (-1,-1), (0,-2),
# (1,-1).  Two cells are adjacent when they differ by one of (1,0), (-1,0),
# (0,1), (0,-1), (1,-1), (-1,1).  The colour of a vertex (x, y) is y mod 3,
# which takes only the values 1 and 2.  Each polyhex is listed by the
# lexicographically least of its twelve dihedral images, each translated so
# that the least q and the least r are both zero.  The 116 records appear in
# increasing number of cells and then in increasing lexicographic order.
#
# Record format.
#
#   POLYHEX id h n m q1 r1 ... qh rh
#       polyhex number id, with h cells, whose graph has n vertices and m
#       edges, and whose cells are (q1, r1), ..., (qh, rh).
#
#   WITNESS colour k x1 y1 c1 ... xk yk ck N M
#       the previous polyhex is not in the golden gap class.  The witness y
#       is supported on the k distinct vertices (xi, yi), all of the stated
#       colour, with y(xi, yi) = ci nonzero, and N = y^T y,
#       M = -y^T (A^2 - 2I) y.  Then 2M - N > 0 and 5N^2 < (2M - N)^2.
#
#   MEMBER name
#       the previous polyhex lies in the golden gap class.
#
#   MEMBERCERT name n c0 c1 ... cn
#       the characteristic polynomial of the named member, on n vertices,
#       by ascending coefficients.
#
#   MEMBERFACTOR name mult d c0 ... cd
#       an irreducible factor over Z, of degree d and multiplicity mult, by
#       ascending coefficients; the product of the factors, with
#       multiplicity, is the characteristic polynomial.
#
#   MEMBERMINROOT name i hnum hden
#       factor number i (counting from zero in the order listed) is the one
#       carrying the smallest positive root, and that root is the unique
#       root of that factor in the interval (0, hnum/hden].
#
# Summary lines.  MAXENTRY, MAXSUPPORT, MAXN and MAXM are the largest
# |y(v)|, the largest number of nonzero entries, and the largest N and M over
# the 113 witnesses; MAXINT is the largest integer that occurs in any of the
# comparisons, namely the larger of (2M - N)^2 and 5N^2.
#
